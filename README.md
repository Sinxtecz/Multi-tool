# 🔐 SINXTECZ Python Security Toolkit

A simple Python-based cybersecurity toolkit that I'm building while learning Python, networking, Linux, and security automation.

This project is mainly for learning how Python can interact with common networking and security tools.

---

## ⚡ Features

Currently available:

- 🏓 Ping
- 🌐 DNS Lookup
- 🔎 Nmap Scan
- 💻 Simple command-line interface
- 🪟 Windows support
- 🐧 Linux support
